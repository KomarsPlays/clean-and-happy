# Clean & Happy ✨

Простое, но эффективное PWA-приложение для планирования домашней уборки.

## Особенности
- **4 зоны**, **25 задач**
- Котики и конфетти! 🐱🎉
- Несколько тем оформления под время суток
- Поддержка установки как PWA-приложения
- Firebase Sync

## Правила разработки

> **Перенесено:** из Dashboard Antigravity, 18.10.2026

* **Кэш PWA.** При любом изменении CSS или JS обновлять `CACHE_NAME` в `sw.js` (сейчас `clean-happy-v60`), иначе на телефоне останется старая версия.
* **Урок Черники.**
  1. Пока идёт дизайн и отладка интерфейса, никаких Service Worker, PWA и GitHub Pages. Вёрстка полируется только локально (Live Server или http-server).
  2. PWA (манифест, кэш, воркер) включается последним этапом, когда багов в интерфейсе точно нет.
  3. Если после сборки PWA всплыла пачка багов дизайна, сразу выключить кэширование (убрать регистрацию `sw.js`) и вернуться в черновик, а не бороться с кэшем.
* **Проверка глазами.** Визуальные изменения (фоны, цвета, обводки, состояния кнопок) проверять в браузере до публикации.
